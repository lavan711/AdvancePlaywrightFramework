# AdvancePlaywrightFramework

Playwright automation framework with reusable API clients, fixtures, page objects, test data, tests, and utilities.

## Project structure

```text
src/
├── api/       API clients
├── config/    Environment configuration
├── fixtures/  Custom Playwright fixtures
├── pages/     Page Object Model classes
├── testdata/  Test data
├── tests/     Test cases
└── utils/     Reusable utilities

docs/          Project documentation
rules/         Project rules
tests/         Playwright tests
```

## Running tests

```bash
npx playwright test
```
